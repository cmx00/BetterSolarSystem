# BetterSolarSystem

[English](README.md) · 3.2.0 预览版 · 需要 Galactic Scale

[下载 3.2.0](https://github.com/cmx00/BetterSolarSystem/releases/tag/v3.2.0)

BetterSolarSystem 是基于 Galactic Scale（GS2）的《戴森球计划》模组。它重新设计太阳系开局，保留八大行星真实的轨道距离比例，拉开天体间距，让太阳系看起来更开阔。

你从木星的卫星木卫二起步，附近有足够的基础矿产，也有需要跨星球开采的稀有资源。其他星球以方便使用常用蓝图的半径 200 为主，同时保留更大的建设星球、小型矿星和巨型气态行星。

![木卫二地表与远处的木星](assets/europa-homeworld.jpg)

## 太阳系布局

天体挤得太近，会让太阳系看起来像一圈大小差不多的球。这里重新安排了 GS2 生成的布局：内侧岩质行星相对紧凑，外侧巨行星相隔更远，气态巨行星明显大于它们的卫星。

八大行星之间保留真实太阳系的轨道距离比例。天体大小、太阳亮度和部分环境则按游戏需要调整。

![太阳系轨道图](assets/solar-system-orbits.png)

*轨道距离采用线性比例。内侧四颗行星在左侧单独放大，便于阅读；天体标记大小与轨道相位仅作示意。*

出生系包含太阳、八大行星、谷神星、冥王星和十三颗卫星，共 23 个行星与卫星。出生地是半径 300 的草原木卫二。为了能正常开局，这里的木卫二设为宜居草原，与真实环境不同。

## 行星尺寸与蓝图

不同半径的星球使用不同的建造网格，原版蓝图放到大星球上可能无法直接使用。因此，星区保留较多半径 200 的星球，用来建设主力工厂。

| 星球半径 | 用途 |
| --- | --- |
| 200 | 与原版常用建设尺度一致，适合铺设工厂和复用同尺寸蓝图 |
| 300 | 提供更大的建设面积，包括出生卫星 |
| 50 | 小型资源据点，适合开采后运往主基地 |

固体星球只使用这三种半径。常规卫星以 200 为主，少量为 50；出生卫星是唯一的 300 半径卫星。四颗气态或冰巨行星采用更大的尺度。跨半径蓝图仍受网格差异影响，本模组不保证它们通用。

## 开局资源

出生地的铁、铜等基础矿产足够建立早期工厂。矿团更集中，便于放置采矿机；较大的星球拥有更多矿团。原油另设流速范围，避免出现单口油井产量过高的问题。

额外矿产分布在出生地和木星的其他卫星上。太阳系内有分形硅石，卡戎等小天体上也安排了稀有矿，后续发展需要建立星际运输。

出生矿团会分散到不同方向，减少主要矿产挤在一个半球的情况。

## 黑雾与防御

轨道拉开后，黑雾舰队和补给舰的路程更长。如果沿用原速度，进攻和补给会花太多时间在路上。因此提高了航行速度与单次补给量。

防御塔的射程和索敌范围并不是一回事。这里同时调整目标搜索与攻击距离，避免敌人已经在射程内，炮塔却找不到目标。攻击层级、俯仰和遮挡等判定保留，信号塔仍需正常建设。

太阳帆寿命也有所延长，减少维持太阳帆发电时需要不断补充的数量。

| 默认调整 | 游戏中的作用 |
| --- | --- |
| 黑雾舰队、补给舰航行速度 ×2 | 缩短长距离航行与补给等待 |
| 补给舰物质、能量容量 ×2 | 每次运输携带更多补给 |
| 新发射太阳帆寿命 ×4 | 减少维持太阳帆发电所需的持续补充 |

倍率以游戏运行时的基础值为参照；其他修改相同机制的模组可能叠加。已发射太阳帆保留原有到期时间。

## 其他恒星系

其他恒星系的主行星数量在 1–8 颗之间变化，还可能有卫星和小型外围天体。布局包括紧凑的岩质系统、热木星、海洋世界和外围巨行星等类型。

有些系统只有少量星球，有些则包含多颗行星和卫星。每个系统都保留可采矿、可建设的星球。

## 安装

需要 **BepInEx 和 Galactic Scale**。可以使用模组管理器安装依赖，再安装上方下载链接中的包；GS2 提供星区生成接口。

创建新游戏时，选择 **Galactic Scale 2** 生成器。Sol 和 Dev 生成器不应用本模组的布局。

手动安装时，先关闭游戏，分别放置两个文件：

```text
BepInEx/plugins/BetterSolarSystem/BetterSolarSystem.dll
BepInEx/patchers/BetterSolarSystem/BetterSolarSystem.Compat.dll
```

换用本包前停用旧 GS2Tweaks、Global Signal Tower 和旧 GS2GameCompat，避免重复修改。配置文件为 `BepInEx/config/cmx.BetterSolarSystem.cfg`。

## 存档

**完整布局需要新建星区。** 旧档保留已有轨道、半径与矿脉；运行时名称修复和平衡调整可以生效，自定义名称会保留。更换模组前请备份存档及其附属文件。

## 参数与兼容

普通固体矿团默认每团 16–24 个矿点，小天体为 12–16 个。半径 300 星球的各类固体矿团数量翻倍，单口油井不跟着翻倍；原油目标流速为 1.5–6/s，未计研究加成。

本预览版按 GS2 2.80.3 编译，已完成生成、名称和防御目标判定的针对性检查。They Come From Void 的完整入侵战斗仍需游戏内验证；本模组不修改它的入侵流程。
