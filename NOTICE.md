# Source and assets

The defense module in this package is a new implementation built around a shared spatial candidate index and the game's validation API. Earlier private builds used a customized Global Signal Tower / PowerfulDefender component; that implementation is excluded from this release source and binaries.

Galactic Scale, BepInEx and Harmony are required separately. No game, Unity, Galactic Scale, BepInEx or other authors' assemblies are bundled.

The included screenshots depict Dyson Sphere Program, whose game artwork belongs to its respective rights holders. The orbit diagram and package icon were drawn for this project. No affiliation with Youthcat Studio is implied.
